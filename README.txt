AL AZIZ FAST FOOD - FIXED WEBSITE

IMPORTANT FIX:
The main index.html now contains its CSS and JavaScript inside the file.
This fixes the common Android content:// preview problem where style.css
and script.js are not loaded when only the HTML file is opened.

HOW TO OPEN ON ANDROID:
1. Download this ZIP.
2. Extract the ZIP (do not open index.html from inside the ZIP).
3. Open the extracted index.html in Chrome.
4. If Android opens a plain file preview, use Share / Open with / Chrome.

GITHUB:
Upload index.html, style.css, script.js and the images folder to the
repository root. GitHub Pages can serve the site from index.html.

FILES:
- index.html: standalone page with embedded CSS and JS (recommended)
- style.css: separate editable CSS copy
- script.js: separate editable JavaScript copy
- images/: folder for your own photos

FEATURES:
- Responsive blue and yellow design
- 18 menu products and 3 combo deals
- Add to Cart, quantity controls and checkout form

NOTE:
Food photos are external illustrative photos and need an internet connection.
Demo checkout saves orders in the visitor's browser only; it does not send
orders to the restaurant. A backend such as Supabase is needed for live orders.
